# Vandalur Zoo Diary

A zoo-themed photo blog about an industrial visit to Vandalur Zoo, Chennai, by students of VIT Chennai.

## Features
- 20 photos, in the order of the original document
- Photo prints with handwritten captions, and a click-to-enlarge viewer
- Sticky trail menu that highlights the current stop
- Responsive layout for phones, tablets and desktops
- Automatic light and dark mode

## Run it
Open `index.html` in any browser. All photos are embedded in the file.

## Live page
https://YOUR-USERNAME.github.io/vandalur-zoo-blog/

## Built with
HTML, CSS and a little JavaScript. Fonts: Alfa Slab One, Nunito and Caveat from Google Fonts.
